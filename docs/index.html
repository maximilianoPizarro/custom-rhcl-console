Core capabilities

A PatternFly 6 OpenShift Console dynamic plugin that surfaces Connectivity Link resources with the logged-in user's RBAC — no service-account token in the browser.

Operations

Gateways & HTTPRoutes

Hostname-first lists, attachment views, backend refs, and effective policy stack after Kuadrant merge/override resolution.

Policies

Auth, Rate Limit, DNS & TLS

Policy inventory and detail pages for AuthPolicy, RateLimitPolicy, TokenRateLimitPolicy, DNSPolicy, and TLSPolicy.

Health

DNS & TLS troubleshooting

Certificate expiry warnings, DNS propagation status, and live probes via the optional dns-prober companion.

API Products

Business-friendly catalog

API Product overview without YAML: plans, API keys with approve/reject flows, and traffic sparklines.

Observability

Traffic & cost

Envoy metrics via in-cluster Prometheus, Grafana/Tempo deeplinks, and cost monitoring for API key tiers.

Packaging

Helm & GitOps ready

Chart on Artifact Hub / GitHub Pages. Deploys plugin, ConsolePlugin CR, ConfigMap, and optional dns-prober.

Install with Helm

Install into the custom-rhcl-console namespace — the plugin hardcodes ConfigMap lookups there. Requires OpenShift 4.19+ and Connectivity Link / Kuadrant.

# Add the Helm repository (GitHub Pages)
helm repo add custom-rhcl-console https://maximilianoPizarro.github.io/custom-rhcl-console/
helm repo update

# Install the plugin (+ dns-prober by default)
helm install custom-rhcl-console custom-rhcl-console/custom-rhcl-console \
  -n custom-rhcl-console --create-namespace
# Or install from the Git repository path (GitOps / local)
helm upgrade --install custom-rhcl-console ./helm/custom-rhcl-console \
  -n custom-rhcl-console --create-namespace

Architecture

Stateless nginx serving the webpack Module Federation bundle over HTTPS :9001 (OpenShift service-CA). Navigation registers via console-extensions.json.

Layer Technology Description
UI React 18, PatternFly 6, Console SDK Dynamic plugin inside the OpenShift Console iframe
Runtime UBI9 nginx-124 (HTTPS :9001) Serves static assets; Console requires HTTPS plugin backends
Registration ConsolePlugin CR Sidebar section + optional dns-prober proxy alias
Companion Quarkus dns-prober (optional) Live DNS / TLS / security-header probes
Auth model User bearer token No plugin ServiceAccount — RBAC-aware empty states
Packaging Helm 3 + Quay.io Chart on this Pages site; CI builds UBI images

GitOps

Wire the chart into OpenShift GitOps the same way as migration-toolkit-rhcl — as a helmApps entry pointing at helm/custom-rhcl-console.

# from-3scale-to-connectivity-link examples/helm/values.yaml
- id: custom-rhcl-console
  enabled: true
  repoURL: "https://github.com/maximilianoPizarro/custom-rhcl-console"
  path: helm/custom-rhcl-console
  targetRevision: "main"
  destinationNamespace: custom-rhcl-console
  syncWave: "10"
